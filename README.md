# WebMarket

> 🇵🇱 Polska wersja: [README.pl.md](README.pl.md)

A plugin for Paper 1.21.x servers (Java 21): **a fictional crypto exchange with its own website**.
Everything runs on the server's own currency only (Vault / EssentialsX). No real money ever enters or leaves the
exchange - the plugin has no payment integration whatsoever.

It replaces the older *PHP + Skript + skript-db* setup: one `.jar` handles the market, bots, events,
in-game menus, commands and the website (built-in HTTP server).

## Features

- 8 default coins (configurable). Prices follow a **market curve that depends on order size**
  (big buys raise the price, big sells lower it; you cannot profit from splitting orders or from buying and instantly selling).
- Sell fee (2% by default).
- Bots that create supply and demand, a market cycle every 5 minutes (market mood, mean reversion, secret admin trend), random events with news.
  Bots and events are **transparent**: they are labelled on the website and in chat, and the site footer mentions them.
- Limit orders (buy when the price drops, sell when it rises) with locked funds.
- Website: candlestick chart, wallet with profit/loss, history, leaderboard, news, live feed, admin panel.
- Login to the website with a **one-time code from the game** (`/gielda link`) - no passwords.
- In-game menu (`/gielda`): wallet, market, broker (BUY 1/10/100/MAX, SELL 1/10/100/ALL).
- Deposit / withdraw between the game and the exchange account (`/wplac`, `/wyplac`); withdrawals go through a crash-safe queue.
- **English and Polish**: commands, chat messages, the website and the default events (see *Language* below).
- Database: SQLite (default, zero setup) or MySQL.

## Requirements

- Paper (or a fork) 1.21.x, Java 21
- **Vault** + an economy plugin (e.g. EssentialsX)

## Installation

1. Put `WebMarket-1.0.2.jar` into `plugins/` (together with Vault and an economy plugin).
2. Start the server - `plugins/WebMarket/config.yml` (fully in English) and `messages.yml` are created.
   Upgrading from 1.0.1 or older? The old `plugins/KryptoGielda/` folder is copied to `plugins/WebMarket/` on the first start
   (config, messages, database, custom website files) and renamed to `KryptoGielda.migrated-to-WebMarket` - you can delete it afterwards.
3. Adjust `config.yml` (currency, coins, website port, `public-url`) and restart the server.
4. In game: `/gielda link` -> enter the code on the website.

Changes to `config.yml` need a restart. `/gieldaadmin reload` only reloads the messages file.

## Commands and permissions

| Command | Description | Permission |
|---|---|---|
| `/gielda` (`menu`, `portfel`, `rynek`, `saldo`, `link`, `help`) | menu and info | `gielda.use` (everyone by default) |
| `/wplac <amount>` (`/deposit`) | from the game to the exchange account | `gielda.use` |
| `/wyplac <amount>` (`/withdraw`) | from the exchange account to the game | `gielda.use` |
| `/gieldaadmin cena\|pump\|dump\|trend <coin> <value>` | manual price control / secret trend | `gielda.admin` (OP by default) |
| `/gieldaadmin wymus`, `event [number\|dodaj\|usun\|import]` | force a market cycle / run, add, delete an event / import the defaults | `gielda.admin` |
| `/gieldaadmin moneta lista\|dodaj\|edytuj\|usun ...` | custom coins without a restart | `gielda.admin` |
| `/gieldaadmin reset potwierdz [wipe]` | reset the exchange (with `wipe` also player accounts) | `gielda.admin` |
| `/gieldaadmin gracz <name> <saldo\|krypto> <dodaj\|odejmij\|ustaw> <value>` | adjust accounts | `gielda.admin` |
| `/gieldaadmin wyplaty [zwroc\|zakoncz <id>]` | inspect and repair payouts interrupted by a crash | `gielda.admin` |
| `/gieldaadmin import [force]` | import from the old exchange (see below) | `gielda.admin` |

The commands also work in English: `/market`, `/deposit`, `/withdraw`, `/marketadmin` and subcommands such as
`price`, `force`, `player`, `coin`, `payouts`.

## Language

`language: pl` or `en` in `config.yml` switches the in-game messages (`messages.yml` / `messages_en.yml`), the website and the
default events. Players can switch the website language with the **PL/EN** button; the browser remembers the choice.
The language of the built-in events is set separately with `simulation.events.default-language` (English by default).

The admin panel on the website is available only to people who logged in with a code generated by a player with the `gielda.admin` permission.
All admin actions are written to the server log (`[AUDIT]`).

## Website - port, HTTPS, security

- The website listens on port **8123** by default (`web.port`). Open it in your host's/server's firewall.
- **Recommended:** put a reverse proxy with HTTPS (nginx/Caddy) in front of the plugin and set `web.bind: 127.0.0.1`,
  `web.secure-cookie: true`, `web.trust-forwarded-headers: true`, `web.public-url: https://market.yourserver.com`.
  Caddy example: `market.yourserver.com { reverse_proxy 127.0.0.1:8123 }`
- Never expose your database port (3306) to the internet. The plugin does not need it with SQLite.
- Built-in protections: one-time codes, HttpOnly + SameSite=Strict session cookies, request rate limits, `Origin` checks,
  request size limits, CSP headers, no external scripts or libraries on the site, all price logic on the server.
- Custom look: copy `index.html`, `style.css`, `app.js`, `i18n.js` (PL/EN texts) from the jar to `plugins/WebMarket/web/` and edit them
  (keep the element ids that `app.js` relies on).

## Live market, events and custom coins

- **Micro-moves**: every few seconds each coin's price really moves by a fraction of a percent (`simulation.micro-ticks`), so the chart
  "pulses" without reloading the page. These are real server-side price changes, the same for all players.
- The website refreshes itself every second; the selected coin, interval and tab are remembered in the browser.
- **Events**: 16 by default - one bull and one bear event per coin (built in, English by default). In the admin panel
  (Admin tab -> market events) you can run any event, **add your own** (coin, price change in %, draw weight, text) and delete custom ones.
  Custom events are stored in the database and are drawn together with the others.
  If your old `config.yml` has its own short `simulation.events.list`, the panel shows only that list - click **"Import default events"**
  to add the missing ones (or remove the `list:` block from the config).
- **Custom coins**: Admin -> "Cryptocurrencies" or `/gieldaadmin moneta dodaj <name> <price> [min max liquidity icon]`. Full configuration:
  name, start price, icon, volatility min/max, liquidity. They work immediately without a restart and can be edited and deleted
  (deletion is blocked while players hold them in wallets or orders). Coins from `config.yml` stay editable in the file only.
- **Price history** older than 48 h is compacted automatically (5-minute candles are kept), so the database does not grow forever.
- Behind an frp tunnel all players appear as 127.0.0.1 - request limits are raised automatically; raise `web.rate-limit-multiplier` if needed.

## Backups

SQLite: copy `plugins/WebMarket/gielda.db` (with the server stopped, or together with the `-wal`/`-shm` files).
MySQL: a standard `mysqldump`.

## Import from the old exchange (PHP + Skript)

**Player balances and portfolios** are migrated. Limit orders and history are not (different price model).
Portfolios get a cost basis equal to the current price (profit/loss counts from the moment of import).

1. In `config.yml`, section `import`: `enabled: true` + the details of the old MySQL database.
2. Restart, then run `/gieldaadmin import`.
3. Players who never joined the server are skipped (`import force` adds them - only for offline-mode servers).
4. After the import remove the password from `config.yml` and **change the old database passwords**.

The import can be repeated - existing accounts are skipped.

## How the price works (short)

After buying `q` units the price is `P*exp(q/Q)` and the cost is `P*Q*(exp(q/Q) - 1)`; selling is the inverse curve minus the fee.
The result depends only on the total amount, not on how it is split, so there is no farming with small orders.
`Q` comes from `market.depth-value-per-percent` (or `coins.<name>.liquidity`). All amounts are integers (cents / 1/10000 of a unit) -
no floating-point rounding errors.

## Troubleshooting

- *"No Vault economy found"* - an economy plugin (e.g. EssentialsX) or Vault is missing.
- *The website does not open* - check the port in the firewall and the server log line "The website is running on port...".
- *A payout stuck in SENDING after a crash* - `/gieldaadmin wyplaty`; **check the player's balance** before `zwroc` (refund to the exchange account) or `zakoncz`.

## Building from source
